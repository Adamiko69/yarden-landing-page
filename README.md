# ירדן רז חבר — דף נחיתה

דף סטטי בעברית לפי התמונה המקורית שסופקה. במחשב נשמרים הפיקסלים המקוריים, עם קישורים חיים וטקסט HTML נגיש. בנייד מוצגים הצילום המקורי ומלל שמסתדר למסך צר. אין תפריטים, אנימציות, מעקב, באנר עוגיות או שירותי צד שלישי בזמן טעינת הדף. פרטי הפקת התמונות: [assets/README.md](assets/README.md).

## הרצה ובנייה

נדרשים Node.js ו־Python 3. אין תלויות npm ואין צורך ב־`npm install`.

```sh
cd /workspace/yarden-landing-page
npm start
```

שרת הפיתוח מאזין בפורט 8000. להכנת הקבצים לפרסום:

```sh
npm run build
```

התוצר נוצר ב־`dist/`. `site.config.json` מכיל את כתובת היעד המתוכננת ל־GitHub Pages; קיום כתובת בקובץ אינו מעיד שהאתר כבר פורסם. בניית Actions מקבלת את הכתובת בפועל מ־GitHub. לאחסון אחר אפשר לשנות את ההגדרה או להריץ `SITE_URL='https://actual-domain.example/' npm run build` עם הכתובת האמיתית. הבנייה יוצרת canonical, תגיות Open Graph עם כתובת תמונה מוחלטת, robots.txt ו־sitemap.xml.

## שינוי פרטי יצירת קשר

בתחילת [contact.js](contact.js), באובייקט `contact`:

- `whatsappNumber`: מספר בינלאומי בספרות בלבד, כרגע `972528337144`.
- `whatsappMessage`: הודעת הפתיחה, כרגע `היי ירדן, אשמח לתאם שיחת היכרות`.
- `email`: כתובת הדוא״ל, כרגע `r.yarden@gmail.com`.

כל הקישורים והפרטים המוצגים מתעדכנים מההגדרות האלה, גם כשהם משתנים ביחס לתמונה המקורית. כדי לשמר גם את הקישורים כאשר JavaScript כבוי, יש לעדכן במקביל את כתובות הגיבוי `href` ואת הטקסטים ב־`index.html`.

שינוי יתר הטקסטים בעיצוב המחשב דורש גם עדכון של תמונת המקור, משום שהכיתוב המקורי נכלל בה. הטקסט הנגיש, המלל הזורם בנייד, תגיות הכותרת והתיאורים וטקסט תנאי השימוש נמצאים ב־`index.html`. הגדרות העיצוב ב־`styles.css`.

## בדיקות

```sh
npm run build
npm test
```

הבדיקות משתמשות ב־Python Playwright, Pillow ו־Chromium המותקנים בסביבת הענן. הן בודקות לחיצות במחשב ובמובייל מדומה, מספר והודעת WhatsApp, מייל, תנאי שימוש, נגישות המתג, אזורי לחיצה וגלילה אופקית. בדיקות התוצר בודקות את הפיקסלים המקוריים במחשב, טעינת תמונות במובייל, גבולות מסך, נתיבים ותגיות שיתוף. הן אינן מפעילות יישומי WhatsApp או דוא״ל במכשיר פיזי ואינן שולחות הודעות.

## פרסום ב־GitHub Pages

תהליך הפרסום נמצא ב־[.github/workflows/deploy.yml](.github/workflows/deploy.yml). הוא מופעל בדחיפה ל־`main` או ידנית, בונה את `dist/` ומפרסם אותו. כל פעולות GitHub מוצמדות ל־commit מאומת של הגרסה הרשמית.

המאגר פרטי. Pages במאגר פרטי תלוי במסלול GitHub מתאים; אין לשנות את נראות המאגר ללא הוראה מפורשת. אם Pages אינו מופעל:

1. בעל הרשאה בחשבון פותח את Settings → Pages במאגר.
2. ב־Build and deployment בוחר Source: **GitHub Actions** ושומר, אם האפשרות זמינה במסלול.
3. מפעיל את `Deploy landing page to GitHub Pages` בלשונית Actions, או דוחף עדכון ל־`main`.
4. אחרי הצלחה, בודק את הכתובת ש־GitHub מציג, את קישורי הקשר ואת תצוגת השיתוף ב־WhatsApp.

בבדיקה הנוכחית הרשאת האינטגרציה מחזירה `403 Resource not accessible by integration` עבור הפעלת Pages. זו מגבלת הרשאה, וקובצי פרסום או build מוצלח אינם מוכיחים שהאתר כבר באוויר. דומיין אישי הוא אופציונלי; GitHub Pages מספק כתובת `github.io` לאחר הפעלה מוצלחת.

יש להשתמש ב־checkout הקיים. כל משימת ענן כבר מבודדת, ואין צורך ב־Git worktree נוסף. תהליכי שרת אינם נשמרים בין משימות ויש להפעיל אותם מחדש כשצריך.
